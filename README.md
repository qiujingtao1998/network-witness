# The code about the paper "Scalable Certification of Entanglement in Quantum Networks"
+ `graph.py` is used to generate date.
+ `graph_plot.py` is used to plot the figure.
+ Note that the bounds for fidelity-based witnesses are determined by the minimum cut, that is, the maximum fidelity of biseparable states and the perfect state is $\alpha=\frac{1}{d^{|\text{min cut}|}}$.
